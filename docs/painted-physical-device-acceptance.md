1. **Portrait orientation:** Open the page holding the handset upright. The **entire** live landscape game appears sideways, including any guide or modal. There is no rotation prompt, distinct portrait UI, clipped gameplay control or page scrolling. Physically turn the handset to landscape, then back and forth once to check stable CSS touch mapping.
2. **Landscape with browser bars visible:** Inspect the whole single-screen game at the default zoom. Verify the browser address/navigation bars and any rounded corners/safe areas do not obstruct actual taps. Try swiping the background and edges; the **page** must not move.
3. **Real touch, not simulated mouse:** Tap outer Red clockwise **once**. A tap never rotates two rings or triggers the underlying world. Follow Next/Previous over Puzzle 01→02→03→02→01 and watch the genuine six-dot campaign progress respond.

5. **Authentic first-puzzle solution:** Reset/return to Puzzle 01. Use the actual on-screen controls in this order (ring names are source-art labels; CW = right arrow, CCW = left arrow): **Violet CW 1; Indigo CCW 2; Blue CCW 1; Green CCW 2; Yellow CW 3; Red CCW 2.** Total is exactly **11**. 6. **Accessibility and motion:** Check visible keyboard focus and Escape/focus return where an actual keyboard is attached; verify any available reduced-motion setting can be honored without disabling logic. Browser zoom/text scaling must not hide the Close or Play button, trap scrolling, or make critical tap targets unusable.
